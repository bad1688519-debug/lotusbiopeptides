LOTUS BIO / CATALOG HELP

How to build a multi-product catalog inquiry

Build one list with exact SKU codes, quantities and destination details.

Start with the approved catalog

Search by product name or SKU. Select the exact specification shown on the product page; a similar name is not a substitute for a matching catalog code. Only listed-price specifications are available in this catalog.

Record boxes, not an ambiguous quantity

For a format labelled 10 vials per box, 2 boxes means 20 vials. Keep box quantity separate from the mass printed on each vial. Do not treat a vial label as an assay result.

Keep each specification on its own line

Use: product / SKU / stated pack / box count / listed unit price. Add a separate line for another strength of the same product. This makes the list easier to verify.

Review the complete inquiry

Check each selected code and quantity in the inquiry list. Include destination country and reply email. The listed subtotal excludes shipping; final availability, freight and terms require confirmation.
