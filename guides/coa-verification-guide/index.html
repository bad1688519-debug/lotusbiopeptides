LOTUS BIO / CATALOG HELP

Request documents for your selected SKU

Connect a document request to the product specification you intend to order.

Include the selected code

Send the product, SKU, pack specification and quantity. Ask which batch is proposed and which available report applies to it.

Match identity and batch reference

Compare the product name, sample identifier, batch or lot reference and report date. A report for another sample does not establish the results of the proposed supply batch.

Read each reported measurement separately

Identity, purity and measured content answer different questions. Ask for clarification if a document does not cover the measurement your procurement process needs.

Record confirmation before finalizing

Save the applicable report and the team’s confirmation with your quotation. Catalog illustrations and label quantities are not substitutes for batch results.
