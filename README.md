# LotusBio Peptides

Independent static website for https://lotusbiopeptides.com.

This repository is separate from the existing lbiopeptides.com website.

## GitHub Pages

Publish the main branch from the repository root. Keep CNAME set to lotusbiopeptides.com. Configure this domain in the new repository's Pages settings and point its DNS to the Pages target. Do not change the old site's repository or Pages settings.

## Local preview

Run node preview.cjs, then open http://127.0.0.1:4173.
